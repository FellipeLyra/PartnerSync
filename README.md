### O Sistema Operacional Inteligente para Equipes de Alta Performance

**PartnerSync** redefine a produtividade transformando a maneira como parceiros e pequenas equipes operam. Esqueça a alternância entre 10 abas diferentes (Trello, Slack, Planilhas, CRM). Centralizamos **TUDO** em uma única interface moderna, fluida e, acima de tudo, **inteligente**.

---

## 🌟 Por que o PartnerSync é Diferente?

O coração do PartnerSync é a nossa **Inteligência Artificial Nativa**. Diferente de sistemas passivos onde você apenas *registra* dados, aqui a IA **trabalha com você**.

*   🧠 **Ela entende o contexto**: Sabe quem são seus clientes, quais são seus projetos e o status das suas finanças.
*   ⚡ **Ela executa**: Não precisa clicar em 20 botões. Apenas diga *"Agende uma reunião com a Tech Corp e crie uma oportunidade de 10k"* e veja a mágica acontecer.
*   🔍 **Ela analisa**: Peça relatórios financeiros ou resumos de projetos e receba insights instantâneos.

## 🚀 Funcionalidades que Transformam o Jogo

### 1. 🤖 PartnerSync AI (Seu Copiloto)
O assistente onipresente que vive no seu chat e no seu painel.
*   **Comandos Naturais**: "Crie uma tarefa urgente para o design", "Qual meu saldo hoje?", "Adicione um cliente".
*   **Gestão Ativa**: A IA pode mover cards no Kanban, registrar transações financeiras e até escrever rascunhos de mensagens.

### 2. 💼 CRM de Classe Mundial
Pare de perder vendas por desorganização.
*   **Pipeline Visual**: Arraste e solte negociações em um funil KanBan intuitivo (Prospecção -> Negociação -> Fechamento).
*   **Visão 360º do Cliente**: Histórico completo de interações, e-mails, notas e valores em um só lugar.
*   **Automação**: Converta conversas informais em Deals estruturados em segundos.

### 3. 🎯 Gestão de Projetos (Kanban 2.0)
Clareza total sobre quem está fazendo o quê.
*   **Quadros Dinâmicos**: Crie colunas personalizadas que se adaptam ao seu fluxo de trabalho.
*   **Rico em Mídia**: Anexe imagens, vídeos e documentos diretamente nos cards.
*   **Prazos Inteligentes**: Visualização clara de atrasos e prioridades.

### 4. � Chat Colaborativo & Contextual
A comunicação da equipe integrada ao trabalho real.
*   **Não é só texto**: Compartilhe arquivos, imagens com pré-visualização em lightbox e vídeos do YouTube player nativo.
*   **Canais Organizados**: Discussões separadas por Projeto para manter o foco.
*   **Thread de Inteligência**: Chame `@chat` em qualquer conversa para trazer a IA para a discussão.

### 5. � Controle Financeiro Integrado
Saúde financeira sem precisar de contador para entender.
*   **Fluxo de Caixa em Tempo Real**: Receitas vs. Despesas atualizadas instantaneamente.
*   **Transparência**: Saiba exatamente para onde o dinheiro está indo com categorias claras.
*   **Relatórios Automáticos**: Deixe a IA resumir seu mês financeiro.

### 6. ⏱️ Time Tracking & RH
*   **Ponto Eletrônico Simplificado**: Botão único para entrada, pausas e saída.
*   **Controle de Equipe**: Saiba quem está online e trabalhando em quê.

## 🛠️ Tecnologia de Ponta (Para Desenvolvedores)

Construído sobre uma stack robusta e escalável, garantindo performance de aplicativo nativo na web.

| Camada | Tecnologia |
| :--- | :--- |
| **Frontend** | React 19 + Vite (Ultra Fast) |
| **Design** | Tailwind CSS + Framer Motion (Animações Fluidas) |
| **Backend** | Firebase (Firestore Realtime, Auth, Storage) |

| **Linguagem** | TypeScript (Segurança e Robustez) |

## 🏁 Comece a Usar

### Instalação Rápida

1.  **Clone o Repositório**:
    ```bash
    git clone https://github.com/seu-usuario/partnersync.git
    cd partnersync
    ```

2.  **Instale as Dependências**:
    ```bash
    npm install
    ```

3.  **Configure o Ambiente**:
    Crie um arquivo `.env.local` com suas chaves do Firebase e OpenAI.

4.  **Rode o Projeto**:
    ```bash
    npm run dev
    ```
    Acesse: `http://localhost:5173`
